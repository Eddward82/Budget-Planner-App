# Assets Directory

This directory contains app assets like icons and splash screens.

## Required Assets

When building for production, you'll need:

- `icon.png` - App icon (1024x1024 px)
- `splash.png` - Splash screen (1284x2778 px)
- `adaptive-icon.png` - Android adaptive icon (1024x1024 px)
- `favicon.png` - Web favicon (48x48 px)

## Generating Assets

You can use tools like:
- [Expo Icon Generator](https://icon.kitchen/)
- Adobe Illustrator
- Figma
- Canva

Or use the Expo asset generation service when building with EAS.
